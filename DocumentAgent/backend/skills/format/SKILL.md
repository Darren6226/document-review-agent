# 发票格式校验 Skill

## 职责

验证发票关键字段的格式是否符合中国增值税发票规范。

## 校验规则

### 1. 发票代码格式

- **规则**: 10位纯数字
- **正则**: `^\d{10}$`
- **示例**: `3100153130`
- **错误提示**: "发票代码应为10位纯数字"

### 2. 发票号码格式

- **规则**: 8位纯数字
- **正则**: `^\d{8}$`
- **示例**: `14641426`
- **错误提示**: "发票号码应为8位纯数字"

### 3. 纳税人识别号格式

- **规则**: 15/18/20位大写字母和数字组合（新版多为18位统一社会信用代码）
- **正则**: `^(?:\d{15}|[A-Z0-9]{18}|[A-Z0-9]{20})$`
- **长度**: 仅允许 15位、18位或20位
- **示例**: `91310115MA1H7YJQ5E`（18位统一社会信用代码）
- **错误提示**: "纳税人识别号应为15/18/20位大写字母与数字组合"

### 4. 开票日期格式

- **规则**: YYYY-MM-DD 格式
- **验证点**:
  - 日期不为空，且能被正确解析
  - 格式正则：`^\d{4}-\d{2}-\d{2}$`（见 patterns.md）
  - **范围校验**（需调用方提供当前日期 `today`）：
    - 晚于 `today` → WARNING（未来日期，疑为录入错误）
    - 早于 `1994-01-01`（增值税制度施行前）→ WARNING（异常早日期）
  - 说明：节假日开票本身合法，仅作人工复核提示，不在此判错

### 5. 金额格式

- **规则**: 数字类型，可为整数或小数
- **验证点**:
  - `total_amount` (合计金额) 为数字
  - `total_tax` (合计税额) 为数字
  - `total_amount_with_tax` (价税合计) 为数字

## 级别定义

- **ERROR**: 格式严重错误，发票无效
- **WARNING**: 格式可疑，需人工确认
- **INFO**: 格式正确
