# 发票格式校验 Skill

## 职责

验证发票关键字段的格式是否符合中国增值税发票规范。

## 校验规则

### 1. 发票代码格式

- **规则**: 10位纯数字
- **正则**: `^\d{10}$`
- **示例**: `3100153130`
- **错误提示**: "发票代码应为10位纯数字"

### 2. 发票号码格式

- **规则**: 8位纯数字
- **正则**: `^\d{8}$`
- **示例**: `14641426`
- **错误提示**: "发票号码应为8位纯数字"

### 3. 纳税人识别号格式

- **规则**: 15/18/20位大写字母和数字组合
- **正则**: `^[A-Z0-9]+$`
- **长度**: 15位、18位或20位
- **示例**: `91310115MA1H7YJQ5E`
- **错误提示**: "纳税人识别号格式不正确"

### 4. 开票日期格式

- **规则**: YYYY-MM-DD 格式
- **验证点**:
  - 日期不为空
  - 日期在合理范围内（不能是未来日期太久）
  - 日期解析成功

### 5. 金额格式

- **规则**: 数字类型，可为整数或小数
- **验证点**:
  - `total_amount` (合计金额) 为数字
  - `total_tax` (合计税额) 为数字
  - `total_amount_with_tax` (价税合计) 为数字

```python
{

    "suggestion": "修正建议"

```

## 级别定义

- **ERROR**: 格式严重错误，发票无效
- **WARNING**: 格式可疑，需人工确认
- **INFO**: 格式正确
