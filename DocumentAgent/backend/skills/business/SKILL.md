# 发票业务规则校验 Skill

## 职责

验证发票的业务逻辑规则，包括税率合规性、发票类型与字段匹配、金额合理性等。

## 校验规则

### 1. 税率合规性校验

**中国增值税标准税率**：
```python
VALID_TAX_RATES = [0.00, 0.01, 0.03, 0.05, 0.06, 0.09, 0.13]
```

- 逐项检查 `line_items` 中的 `tax_rate`
- 找到最接近的标准税率，计算差值
- 差值 > 0.001 → WARNING
- **提示**: "中国增值税标准税率为: 0%, 1%, 3%, 5%, 6%, 9%, 13%"

### 2. 发票类型与字段匹配校验

**专用发票额外要求**：
- 必须有 `purchaser_tax_id`（购买方纳税人识别号）→ ERROR
- 必须有 `payee`（收款人）→ ERROR
- 必须有 `drawer`（开票人）→ ERROR

**判断逻辑**：
```python
is_special = '专用' in invoice_type
```

### 3. 金额合理性校验

- 含税金额为负数 → ERROR
- 含税金额超过1000万 → WARNING（异常大额）

### 4. LLM 智能校验（可选）

如果配置了 LLM，可以进行深度业务规则校验：
- 购买方和销售方是否为同一主体
- 商品或服务描述是否清晰合理
- 单价、数量、金额是否合理匹配
- 是否存在明显的数据异常

**LLM Prompt**：
```
你是一个专业的中国增值税发票审核专家。请分析以下发票数据，检查是否存在业务逻辑问题...
```

## 输出格式

```python
{

    "level": "error|warning|info",
    "category": "业务规则校验",
    "message": "校验结果描述",
    "field": "字段名",
    "expected": "期望值",
    "actual": "实际值",
    "suggestion": "修正建议"

```

## 级别定义

- **ERROR**: 违反强制性业务规则
- **WARNING**: 不符合常规业务逻辑，需人工确认
- **INFO**: 业务规则校验通过
