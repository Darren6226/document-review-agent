# 计算校验公式

## 核心公式

### 1. 价税合计
```
价税合计 = 合计金额 + 合计税额
total_amount_with_tax = total_amount + total_tax
```
- 容差：0.02元

### 2. 行项目金额合计
```
合计金额 = SUM(行项目.amount)
total_amount = SUM(line_items[].amount)
```
- 容差：0.02元

### 3. 行项目税额合计
```
合计税额 = SUM(行项目.tax_amount)
total_tax = SUM(line_items[].tax_amount)
```
- 容差：0.02元

### 4. 单项税额
```
税额 = 金额 × 税率
tax_amount = amount × tax_rate
```
- 容差：0.02元

## 中国增值税税率表

| 税率 | 适用范围 |
|------|----------|
| 0% | 出口货物、跨境应税行为 |
| 1% | 小规模纳税人（疫情期间优惠） |
| 3% | 小规模纳税人、部分简易计税 |
| 5% | 不动产租赁、销售不动产 |
| 6% | 现代服务业、金融业 |
| 9% | 交通运输、建筑、农产品 |
| 13% | 一般货物销售、加工修理 |

## 金额合理性

- 最小值：0（不能为负）
- 最大值：10,000,000（超过1000万需警告）
