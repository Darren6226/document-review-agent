# 买卖合同专属审核规则

## rule_id 前缀：SALES

### SALES.subject - 标的物条款（严重程度：high）

1. 标的物应明确具体（名称、规格、型号、数量）
2. 标的物应可特定化（避免笼统描述）
3. 数量单位应规范（件/吨/米等，不用"一批"等模糊表述）
4. 质量标准应明确引用（国标/行标/企标/样品）

### SALES.delivery - 交付条款（严重程度：high）

1. 交付时间应明确（具体日期或合理期限）
2. 交付地点应明确（避免"另行通知"）
3. 交付方式应明确（运输方式、费用承担）
4. 风险转移时点应明确（交付时/签约时/约定时）
5. 标的物毁损灭失风险约定应符合法律规定

### SALES.inspection - 验收条款（严重程度：medium）

1. 验收期限应明确（收到后 X 日内）
2. 验收标准应明确（与质量条款一致）
3. 异议提出期限应明确（表面瑕疵/隐蔽瑕疵分别约定）
4. 未及时验收的法律后果应约定

### SALES.payment - 价款条款（严重程度：high）

1. 价款金额应明确（大小写一致——注：大小写一致性由确定性管线校验）
2. 支付方式应明确（一次性/分期/预付）
3. 支付时间应明确（与交付关联）
4. 发票类型应约定（增值税专用/普通）
5. 价款是否含税应明确

### SALES.warranty - 质量保证（严重程度：medium）

1. 质保期限应明确（不得低于法定最低期限）
2. 质保范围应明确（哪些部件/哪些问题）
3. 质保责任方式应明确（修理/更换/退货）
4. 质保期起算点应明确（交付日/验收日/安装日）

### SALES.ownership - 所有权保留（严重程度：medium）

1. 约定所有权保留的，应明确保留条件（付清全款前）
2. 所有权保留期间的标的物风险承担应约定
3. 买方处分标的物的限制应约定

### SALES.breach - 违约责任（严重程度：high）

1. 逾期交货/逾期付款的违约金应明确
2. 质量不合格的责任应明确（退货/降价/赔偿）
3. 根本违约的解除权应约定
4. 违约金与赔偿损失的关系应明确
