# 租赁合同专属审核规则

## rule_id 前缀：LEASE

### LEASE.rent - 租金与押金（严重程度：high）

1. 租金金额应明确（大小写一致——注：大小写一致性由确定性管线校验）
2. 租金支付周期应明确（月/季/年）
3. 租金支付时间应明确（提前支付/到期支付）
4. 押金金额应合理（通常不超过 2 个月租金）
5. 押金退还条件与时间应明确
6. 租金调整机制应约定（固定/递增/随通胀调整）

### LEASE.term - 租期与续租（严重程度：high）

1. 租赁期限应明确（起止日期——注：日期合法性由确定性管线校验）
2. 租赁期限不得超过 20 年（超过部分无效）
3. 续租条件应明确（优先续租权、通知期限、租金调整）
4. 续租未约定时的处理（自动续期/转为不定期）

### LEASE.maintenance - 维修责任（严重程度：medium）

1. 主体结构维修责任应明确（通常出租方）
2. 日常维修责任应明确（通常承租方）
3. 维修通知义务应约定（承租方发现瑕疵应及时通知）
4. 维修不及时的责任承担应约定

### LEASE.use - 使用限制（严重程度：medium）

1. 用途应明确（居住/办公/经营）
2. 转租限制应明确（禁止/经同意可转租）
3. 改造装修限制应约定（经同意/恢复原状）
4. 不得从事违法活动的兜底条款

### LEASE.priorities - 优先权（严重程度：medium）

1. 优先购买权应约定（出租方出售时承租方优先）
2. 优先承租权应约定（同等条件下优先续租）
3. 优先权的行使条件与期限应明确
4. 优先权放弃的认定标准应约定

### LEASE.termination - 解除与恢复（严重程度：high）

1. 解除条件应明确（违约情形/协商解除）
2. 提前通知期限应约定
3. 退房时房屋状态要求应明确（恢复原状/现状返还）
4. 装修物处理应约定（拆除/补偿/归出租方）
5. 违约解除的违约金/赔偿应明确
