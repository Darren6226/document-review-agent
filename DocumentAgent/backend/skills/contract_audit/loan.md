# 借款合同专属审核规则

## rule_id 前缀：LOAN

### LOAN.interest - 利率条款（严重程度：high）

1. 利率不得超过合同成立时一年期贷款市场报价利率（LPR）的四倍
2. 利率表述应明确（年利率/月利率/日利率，不得混用）
3. 复利计算应符合规定（不得利滚利超过法定上限）
4. 不得约定"砍头息"（预先扣除利息）
5. 逾期利率应明确，且不得超过法定上限
6. 违约金/服务费/管理费等总和不得超过利率上限

### LOAN.principal - 本金条款（严重程度：high）

1. 借款金额应明确（大小写一致——注：大小写一致性由确定性管线校验）
2. 借款币种应明确
3. 借款用途应明确（不得用于非法活动）
4. 交付方式应明确（转账/现金，金额大时建议转账）

### LOAN.repayment - 还款条款（严重程度：high）

1. 还款期限应明确（具体日期或条件——注：日期合法性由确定性管线校验）
2. 还款方式应明确（到期一次性/分期/等额本息/等额本金）
3. 分期还款的每期金额与时间应明确
4. 还款顺序应约定（先息后本/先本后息/本息并还）

### LOAN.guarantee - 担保条款（严重程度：high）

1. 担保方式应明确（保证/抵押/质押/定金）
2. 保证方式应明确（一般保证/连带责任保证）
3. 保证范围应明确（本金/利息/违约金/实现债权费用）
4. 保证期间应明确（约定不明时为主债务履行期届满之日起 6 个月）
5. 抵押物应特定化（名称、数量、价值、登记）
6. 抵押登记义务应约定

### LOAN.prepayment - 提前还款（严重程度：medium）

1. 提前还款是否允许应明确
2. 提前还款通知期限应约定（通常提前 15-30 日）
3. 提前还款是否支付违约金应明确
4. 提前还款的利息计算方式应约定（按实际借款天数/按约定）

### LOAN.breach - 违约责任（严重程度：high）

1. 逾期还款的违约金/罚息应明确
2. 借款人未按约定用途使用的责任应约定
3. 借款人提供虚假资料的责任应约定
4. 出借人未按时交付本金的责任应约定
5. 加速到期条款应约定（何种情形下可要求提前还款）

### LOAN.dispute - 争议解决（严重程度：medium）

1. 管辖约定应明确（原告所在地/被告所在地/合同履行地）
2. 借款合同履行地认定：接受货币一方所在地
3. 送达地址确认条款应约定（避免诉讼时无法送达）
